# Linuxroom v0.4.1

[English README](README.en.md) · 日本語

<img src="docs/images/linuxroom-character.png" align="right" width="120" alt="杖と本を持つLinuxroomのキャラクター">

**ひとつずつ、つないでいこう。**<br>
*Build your Linux command skills, one step at a time.*

[ブラウザで学習する](https://retiacole.github.io/linuxroom/) · [オフライン版をダウンロード](https://github.com/retiacole/linuxroom/releases/latest/download/linuxroom.html)

Linuxコマンドに初めて触れる人が、ファイルの移動・閲覧から、検索・列の抽出・集計・保存までを段階的に練習する教材です。前のコマンドに処理を一つずつ足し、パイプの途中結果を見ながら組み立てます。

初級・応用・発展の3段階、初級36・応用47・発展36、合計119課題を収録しています。初版の36課題のIDと学習順序を保ち、検索条件の組み立て、複数ファイルの照合、JSONの集計へと進みます。

このアプリと教材はOpenAI Codex（AI）を使って作成しました。仮想シェルは [Logroom](https://github.com/retiacole/logroom) のMITライセンスの実装を利用・拡張しています。

<br clear="right">

## はじめ方

[公開版](https://retiacole.github.io/linuxroom/)をブラウザで開くか、オフライン版の `linuxroom.html` を保存して開きます。JavaScriptが使えるブラウザがあれば、インストール、Linux環境、アカウントは不要です。教材・スタイル・プログラムをHTML一つに同梱し、読み込み後の演習中はインターネットに接続しません。

ヘッダーの **Language** メニューで **日本語 / English** を選べます。119課題の説明・課題・ヒント・解答例の案内、学習マップ、コマンド帳、採点結果、保存画面を英語で利用できます。選択はこのブラウザに保存され、進捗ファイルにも含まれます。作業ファイル、現在地、入力途中のコマンド、履歴、修了・ヒント記録を保ったまま切り替わります。

コマンドや教材のファイル本文は両言語で共通です。たとえば追記課題の `確認開始`・`確認完了` は正解に使うサンプル文字列なので、英語でも同じ文字を入力します。英語の説明に意味と入力方法を記載しています。v0.1〜v0.3の進捗は引き続き利用できます。

1. 「学習を始める」から最初の課題へ進みます。
2. 短い説明と今回のミッションを読み、ターミナルにコマンドを入力します。
3. Enterで実行し、出力を確かめます。プロンプトの `$` は入力しません。
4. 答え合わせをして、次の課題へ進みます。
5. パイプの章では段階を選び、各コマンドの入力・出力を確かめます。

ホームの段階別カードや学習マップから、任意の段階・課題を選べます。各段階の途中の課題、入力、作業ファイルを保存するので、復習と先の課題を行き来できます。時間制限・誤答の減点はありません。ヒントと解答例を使い、実際に操作して理解を確かめてください。解答例を開くだけではクリアになりません。

## 学習の流れ

| 段階 | 課題数 | 学ぶこと |
| --- | --- | --- |
| 初級編 | 36 | 移動・閲覧・検索・列の抽出を覚え、パイプで集計・保存 |
| 応用編 | 47 | 正規表現・周辺行・複数ファイル検索、整形、条件付き集計を組み合わせる |
| 発展編 | 36 | ファイル情報・UTC日時・差分・照合・JSON集約を使い、調査結果を作る |

初級編の内容：

| 章 | 内容 |
| --- | --- |
| ターミナルの入口 | コマンドの入力、引数・オプション、ヘルプ |
| 場所とファイル | pwd、ls、cd、絶対・相対パス |
| ファイルを読む | cat、head、tail、lessとq |
| 行を探す | grep、引用符、行番号、除外 |
| つないで数える | パイプ、標準入出力、wc |
| 列を取り出す | cut、awk |
| 並べて集計する | sort、uniq -c、sort -nr |
| 結果を保存する | mkdir、cp、mv、リダイレクト、tee |
| JSONを読む | jqのフィールド抽出と条件指定 |
| 卒業実習 | 新しいデータで検索・抽出・集計・保存 |

途中で同じ短い記録を使うので、コマンドを足すたびに何が変わったか比べられます。用語と記録の意味は課題の中で説明し、攻撃の判断などの専門知識は前提にしません。

応用編では `grep -F` から正規表現、周辺行、再帰検索へ進み、`find`・`rg`・`tr`・`sed`・`column` などを練習します。発展編では `diff`・`comm`・`join`・`paste`・`xargs`、`awk`の集約、`jq`の配列・グループ集計などを追加します。最後は複数の処理をつなぎ、結果をファイルにまとめます。

本版で対応する49コマンドは、課題の解答例または実行できる見本で練習できます。コマンド帳から関連する練習課題へ移動できます。新しいコマンドを一度に覚える必要はなく、初級だけでもSOCroom-easyへ進めます。

操作を間違えたら「この課題をやり直す」で、その課題のファイルと現在地を初期状態に戻せます。他の課題の進捗は保ちます。自由練習では課題から離れて試せます。

## v0.3で追加した操作

入力リダイレクト `<`、`ls -lh`／`ls -lt`、400行のログの先頭・末尾・件数確認、`tail -n +2`、`head -c`、`&&` と `;`、`2>/dev/null`、`$?` の11課題を追加しました。プロンプトは `analyst@linuxroom:~$` と表示され、移動すると現在地が変わります。

`cat file | tr ...` と `tr ... < file` のように目的が同じ操作は、パイプ自体を練習する課題を除き受け入れます。順序が必要な複数ファイル検索には `sort` を加え、`du` はディレクトリ自身のサイズを除くファイルの合計で練習します。

## ターミナル操作

- Enter：入力したコマンドを実行
- 上下キー：実行履歴を呼び出す
- Tab：コマンドやファイル名を補完
- Ctrl+C：入力を取り消す／閲覧画面を閉じる
- Ctrl+L：ターミナルの表示を消す
- `less`・`more`の閲覧中は `q`：閉じる
- `help コマンド名`：この教材で対応する構文を見る

`help` は本教材用のコマンド案内です。実際のLinuxで外部コマンドを調べる方法には `man` や各コマンドの `--help` などがあります。本版の `man コマンド名` は教材内ヘルプを表示する別名です。実機のマニュアルそのものは同梱せず、表示は `q` で閉じます。

## 対応範囲

ブラウザ内の仮想テキストファイルを操作する学習用シミュレーターです。実際のOSや個人のファイルを変更しません。データはすべて架空です。

コマンドは学習用の部分実装です。終了コードを表す`$?`以外のシェル変数、スクリプト、任意のプログラム実行、パッケージの追加、実ネットワーク通信、権限管理、`tail -f`による追従などは再現しません。`vi`・`view`・`sl`の専用画面も本版の対象外です。対応オプションはアプリ内の `help` で確認できます。

本教材の `ls` は読みやすさのため常に1列で表示します。実機の端末では横並びになり、`ls -1` やパイプへの出力では1列になります。`ls -l`／`stat` の更新日時は仮想メタデータ（UTC）であり、手元のファイルの更新日時ではありません。`file` の形式表記や `diff -u` の日時欄は実機・バージョンにより異なります。GNU系の構文を中心としており、macOSのBSD系コマンドとはオプションが異なる場合があります。

ファイルを開いた結果と、パイプの各段の入力・出力は一度の実行で記録します。途中表示のためにコマンドを再実行しないので、追記やファイル移動が二重に起きることはありません。

学習課題では対象コマンドの操作と出力・ファイル状態を確認します。卒業課題では目的の達成を重視します。あらゆる等価なシェルプログラムの正しさを証明する採点器ではありません。

## 保存

ブラウザのlocalStorageの専用キー `linuxroom.progress.v1` に進捗と作業ファイルを、`linuxroom.ui.v1` に入力途中の文字や画面の記録を保存します。LogroomやSOCroom-easyの進捗は変更しません。課題ごとの作業状態も復元します。

v0.1の保存形式と初級36課題のIDを維持しています。同じ保存領域で開くか、旧版で書き出したJSONを「読込」すると、クリア・ヒント・作業ファイルを引き継ぎ、新しく加わった課題を未完了として追加できます。HTMLを置く場所やファイル名を変える前に、旧版でJSONを保存しておくと確実です。

ローカルのHTMLと公開版は保存領域が異なるため、進捗は自動で移りません。ローカル版の「進捗の保存」から「進捗ファイルをダウンロード」でJSONを保存し、公開版の同じ画面から「進捗ファイルを読み込む」で取り込んでください。公開版からオフライン版へ移す場合も同じ手順です。同じブラウザ・公開URLで利用を続ける場合は、アプリの更新後も進捗を引き継ぎます。

ブラウザの制限やプライベート閲覧、HTMLの移動により、自動保存を利用できないことがあります。自動保存できない場合は画面で通知します。「保存」からJSONを取り出すと、別の環境でも「読込」で再開できます。読込は確認後に現在のLinuxroomの進捗を置き換えます。

v0.2の108課題もIDとクリア履歴を維持します。400行のログを追加した閲覧課題だけは、旧作業ファイルを残したまま新しい練習ファイルを補充します。

正解も含めた全データをHTMLに同梱しています。自習用であり、改ざん防止付きの試験や認定には使いません。

## 次の教材

推奨順は Linuxroom → [SOCroom-easy](https://github.com/retiacole/socroom-easy) → [Logroom](https://github.com/retiacole/logroom) → SOCroom です。Linuxroomでコマンド操作、SOCroom-easyでログの読み方、Logroomでコマンドを使ったログ調査を練習します。外部教材へのリンクを開くときだけ通信が発生します。ほかの教材本体はこの配布物に含みません。

## 開発

Node.js 22以上で、外部パッケージなしにビルドできます。

```sh
node build.js
```

ビルドするとオフライン配布用の `linuxroom.html` と、静的公開用の `docs/index.html`・`docs/linuxroom.html`・`docs/.nojekyll` を生成します。両方のHTMLは同じ内容です。静的ホスティングでは `docs/` を配信ルートに指定します。

テストではjsdom、ブラウザ確認ではPlaywrightを使います。開発用依存関係は受講者には不要です。

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

既存Chromeを使うときは `LINUXROOM_BROWSER_CHANNEL=chrome npm run test:browser` を実行します。

GitHub Pagesは `main` ブランチの `docs/` を配信します。リポジトリの「Settings → Pages」で、公開元を「Deploy from a branch」、ブランチを `main`、フォルダを `/docs` に指定します。

更新時は上の順で `npm ci` → `npm run build` → `npm test` → `npm run test:browser` を実行し、確認を終えてからソースと生成された `linuxroom.html`・`docs/` をコミットして `main` へpushしてください。Pagesはコミットされた `docs/` を公開するため、ソースを変えたときは必ず再ビルドし、生成物も更新します。

```text
src/data.js       初級編36課題・練習用ファイル・判定条件
src/data-levels.js 段階の定義・初級への段階タグ追加
src/data-applied.js 応用編47課題
src/data-advanced.js 発展編36課題
src/data-en.js     全119課題の英語説明・課題文
src/concepts-en.js 用語と定義の英訳
src/examples-en.js 見本ごとの説明の英訳
src/hints-en.js    段階的ヒントの英訳
src/i18n.js        UI・コマンド帳の英訳と安全な言語切替
src/shell.js      Logroom由来の仮想シェルと実行記録
src/engine.js     チュートリアル採点・セッション・進捗
src/app.js        学習画面とターミナル
src/style.css     スタイル
src/ui.html       単一HTMLのひな形
tests/           教材・採点・UI・ブラウザ確認
build.js         オフラインHTML・静的公開用HTML生成
linuxroom.html   配布版
docs/            GitHub Pages配信物（ビルド後にコミット）
```

テストでは119課題の解答、説明中の例を実行した後の解答、途中保存からの復元、49コマンドの網羅、旧版データの移行を確認します。`diff`の「差分あり（終了状態1）」は課題で明示した場合のみ正当な結果として扱い、実行エラーとは区別します。ブラウザテストでは画面操作・段階移動・入出力の途中表示・JSONの保存と読込・モバイル表示・通信不要を確認します。
