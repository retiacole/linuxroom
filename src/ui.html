KEEP IT HANDY
コマンド帳
覚えていなくても大丈夫。必要なときに見ながら試そう。
プロンプトの読み方
analyst@linuxroom:~$
analyst
操作しているユーザー名
linuxroom
ホスト名（コンピューター名）
:~
: の後ろは現在地。~ は /home/analyst の省略。cd で移動すると ~/logs などに変わる
$ / #
一般ユーザー / 管理者の目印としてよく使われる。この教材は一般ユーザーの $
プロンプトの見た目は環境によって変わります。プロンプト自体は入力せず、その後ろにコマンドだけを打ちます。
ターミナルの操作
Enter
コマンドを実行
↑ / ↓
実行したコマンドを呼び出す
Tab
コマンド・ファイル名を補完
Ctrl + C
入力を消す / 閲覧画面を閉じる
Ctrl + L
ターミナルの表示を消す
less / more で q
閲覧を終えてターミナルへ戻る
実機では man grep などでマニュアルを調べます。この教材では man を help と同じ学習用の案内にしています。
